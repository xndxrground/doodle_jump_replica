# 🦘 Doodle Jump — космическая прыгалка

Аркадная игра, в которой нужно прыгать по платформам как можно выше. Собирай монеты, используй бонусы и избегай врагов. Три уровня сложности, админ-режим, система жизней и настройки звука.

## 🎮 Игровой процесс

Игрок управляет персонажем, который постоянно падает вниз. Чтобы не упасть, нужно приземляться на платформы. Каждая платформа даёт новый прыжок вверх. Чем выше забирается игрок, тем сложнее: появляются враги, ломающиеся и движущиеся платформы.

### 🧱 Типы платформ

| Платформа | Цвет | Эффект |
|-----------|------|--------|
| Обычная | 🟢 Зелёная | Обычный прыжок |
| Ломающаяся | 🟫 Коричневая | Исчезает через 0.5 сек |
| Движущаяся | 🔵 Синяя | Двигается влево-вправо |
| Пружинящая | 🟣 Фиолетовая | Высокий прыжок |

### 🪙 Монеты

| Тип | Очки | Цвет |
|-----|------|------|
| Бронзовая | +10 | 🟤 |
| Серебряная | +25 | ⚪ |
| Золотая | +50 | 🟡 |

### 🛡️ Бонусы

| Бонус | Эффект |
|-------|--------|
| **Джетпак** | Полёт вверх 2 секунды |
| **Пузырь** | Защита от 1 врага (щит) |

### 👾 Враги

Красные летающие монстры. При касании игрок теряет 1 жизнь. Защита от пузыря уничтожает врага.

### ❤️ Жизни

- У игрока **3 жизни** на уровень
- При потере жизни — временная неуязвимость (1 секунда, игрок мигает)
- Иконки сердец отображаются в правом верхнем углу

## 🎛️ Управление

| Клавиша | Действие |
|---------|----------|
| **← / A** | Движение влево |
| **→ / D** | Движение вправо |
| **Пробел** | Прыжок / Подтверждение в меню |
| **ESC** | Пауза / Закрыть окно настроек |
| **F2** | Админ-режим (свободный полёт) |
| **F4** | Спавн всех предметов в ряд |
| **Enter** | Подтвердить выбор в меню |

### 🧭 Навигация по меню

| Клавиша | Действие |
|---------|----------|
| **← / →** | Переключение между кнопками |
| **Enter / Пробел** | Выбрать уровень / Открыть настройки |

## 🎚️ Уровни сложности

| Уровень | Скорость подъёма | Враги | Типы платформ |
|---------|-----------------|-------|---------------|
| 1 (лёгкий) | Медленная | Редко | Только зелёные |
| 2 (средний) | Средняя | Чаще | Зелёные + синие + коричневые |
| 3 (сложный) | Быстрая | Часто | Все типы (зелёные, синие, фиолетовые, коричневые) |

## 👑 Админ-режим (F2)

- Свободный полёт в любом направлении (W/A/S/D или стрелки)
- Прохождение сквозь врагов и платформы
- Камера не двигается за игроком
- Визуальное свечение вокруг игрока

## ⏸️ Пауза (ESC)

- Нажми ESC во время игры — игра остановится
- Появится текст "PAUSED" по центру экрана
- Нажми ESC ещё раз — игра продолжится

## 🔊 Настройки звука

- Кнопка "Громкость" в главном меню
- Ползунок от 0 до 100%
- Значение сохраняется в браузере

## 🖼️ Ассеты

Игра использует собственные текстуры:
- Игрок (2 кадра анимации)
- Платформы (4 типа)
- Монеты (3 типа × 4 кадра анимации + иконки для Game Over)
- Джетпак (3 текстуры)
- Пузырь (2 текстуры)
- Враг (2 кадра анимации)
- Сердца (полное и пустое)
- Растения (трава, грибы)
- Облака для фона

## 🚀 Технологии

- HTML5 Canvas
- Vanilla JavaScript
- CSS3
- LocalStorage (сохранение рекорда и громкости)
